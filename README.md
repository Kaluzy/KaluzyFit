# KaluzyFit — The Journey Beyond 190

KaluzyFit is a living, personal fitness book and tracking system built around five pillars:

1. Vegetable-centered, protein-supported meals
2. Home strength training and daily movement
3. Sleep and recovery
4. Mindset and planned enjoyment
5. Honest tracking and weekly adjustment

## Website

This repository contains a static website designed for GitHub Pages. Open `index.html` locally or publish the `main` branch from the repository root through GitHub Pages.
